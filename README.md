# Посмотри в окно

Учебный проект курса «Веб-разработчик» Яндекс Практикума. Одностраничное приложение для поиска и просмотра видео из разных городов в разное время суток.

## Функциональность

- Загрузка карточек с видео из внешнего API при открытии страницы.
- Поиск видео по городу и времени суток (утро, день, ночь).
- Переключение основного видео по клику на карточку.
- Подгрузка дополнительных карточек по кнопке «Показать ещё» (пагинация).
- Прелоадеры на время загрузки данных.
- Обработка ошибок: сообщение, если видео не найдено или произошла ошибка запроса.

## Стек

- HTML5
- CSS3 (Flexbox, Grid, CSS-переменные, псевдоклассы `:has()`, `:focus-visible`, `:checked`)
- JavaScript (ES6+, `fetch`, `async/await`, работа с `<template>`)
- Методология БЭМ
